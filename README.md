# Dhruv Boghani | Personal Portfolio

A sleek, modern, and highly interactive personal portfolio built to showcase my backend expertise, full-stack projects, and AI integrations. 

## 🚀 Features

- **Modern Tech Stack**: Built with React, Vite, and Tailwind CSS.
- **Dynamic Animations**: Smooth scroll reveals, hover effects, and spring-animated modals powered by Framer Motion.
- **Glassmorphism UI**: Beautiful, premium dark-mode aesthetic with frosted glass elements, subtle glowing borders, and custom gradients.
- **Responsive Design**: Fully responsive grid layouts tailored for an optimal experience across mobile devices, tablets, and large desktops.
- **Project Showcases**: Custom, detailed project dialogs showcasing system architecture, tech stacks, and live links.
- **Custom Theming**: Overhauled application styles including custom global scrollbars and refined typography.

## 🛠️ Built With

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)

## 📂 Project Structure

```text
src/
├── components/          # Reusable UI elements (Navbar, Footer, Modals)
│   └── Project/         # Individual detailed project view components
├── page/                # High-level route components (Home, About, Skills, etc.)
├── sections/            # Modular page sections (Hero, About, Project Grids)
├── App.jsx              # Main application router
└── index.css            # Global styles and Tailwind configuration
```

## 💻 Getting Started

To run this project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Dhruv-Boghani/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
