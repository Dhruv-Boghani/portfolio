# Typography and Sizing Preferences

- **Headline Font Sizes**: Do not use extremely large text sizes (e.g., `text-6xl` to `text-[7rem]`) for section headers or hero titles unless explicitly requested. Prefer standard, readable scaling like `text-4xl md:text-5xl lg:text-6xl` for major page titles, and `text-3xl md:text-4xl lg:text-5xl` for secondary section headers.
- **Body Text Sizes**: Avoid using oversized body text like `md:text-lg` or `text-xl` for standard paragraphs and descriptions. Stick to standard sizes like `text-sm md:text-base` for body copy unless specifically designing a pull quote or a lead-in statement.
- **Copy and Context**: When populating text or generating copy for a component, always verify if there are reference files (like `resume.pdf`) available in the workspace to draw real context from, instead of relying solely on placeholder text from screenshots or default templates.
